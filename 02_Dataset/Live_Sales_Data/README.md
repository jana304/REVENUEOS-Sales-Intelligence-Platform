# Live Sales Data

REVENUEOS uses Google Forms and Google Sheets
for live sales opportunity collection.

Google Sheets Workbook:
SalesPulse AI — Live Sales Database

Worksheets:
- Live_Sales_Responses
- Sales_Analytics

Python Connection:
Streamlit_App/google_sheets_connection.py

The live data is retrieved directly from Google Sheets.

This folder is reserved for optional CSV exports
and local backup datasets.

Do not store credentials or confidential customer
information in this folder.
